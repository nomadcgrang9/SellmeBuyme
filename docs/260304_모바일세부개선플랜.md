## 이슈 1. 채팅 버튼 → 와글와글이 뜨는 문제

### 현황

- 파일: `src/components/mobile/MobileRegisterNav.tsx`
- `onChatClick` props로 Hero.tsx에서 콜백 전달
- Hero.tsx L3807~3809:

```tsx
onChatClick={() => {
  window.location.href = '/wagle';
}}
```

즉, "채팅" 탭을 클릭하면 `/wagle` (와글와글 피드 페이지)로 이동함

### 원인 분석

- `MobileRegisterNav.tsx` 4번 버튼 레이블 = "채팅", 아이콘 = MessageCircle
- 그런데 실제 동작은 `/wagle` (와글와글 커뮤니티 피드)로 페이지 이동
- 즉, 버튼 이름≠실제 기능 불일치 + 실제 1:1 채팅(/chat)은 연결 안 됨

### 수정 방향

**옵션 A: 버튼 라벨/기능 정렬 (권장)**
- "채팅" 버튼 → 실제 1:1 채팅(/chat)으로 연결
- 와글와글은 이슈 4에서 별도 버튼 추가로 해결

**옵션 B: UI 조정만**
- 버튼 라벨을 "채팅" → "와글와글"로 변경하고 현 동작 유지
- 단, 실제 채팅 접근 경로 없음 → 사용자 혼란

**결론: 옵션 A 권장.** 채팅 버튼은 실제 채팅방(/chat)으로. 와글와글은 새 버튼 추가.

## 이슈 3. 등록 3버튼 작동 안 함

### 현황 (Hero.tsx L3500~3583)

#### 3-1. 구직등록 버튼

```tsx
onClick={() => {
  if (!user) {
    setPendingAction('register');
    setAuthModalInitialTab('login');
    setIsAuthModalOpen(true);
    return;
  }
  setIsTeacherModalOpen(true);  // ← TeacherMarkerModal 오픈
}}
```

- **문제**: `setIsTeacherModalOpen(true)` 호출 → TeacherMarkerModal 오픈
- 현재 TeacherMarkerModal: 지도 위에 마커 핀 찍는 예전 플로우
- **올바른 플로우**: 프로필 기반 구직카드 등록 폼 (데스크탑: `useSidePanelStore.getState().openPanel('register')`)

#### 3-2. 공고등록 버튼

```tsx
onClick={() => {
  if (!user) { ... }
  setLocationPickerType('jobPosting');
  setIsLocationPickerOpen(true);  // ← 위치선택 → 예전 플로우
}}
```

- **문제**: FullScreenLocationPicker로 이동 (지도에서 위치 선택하는 구버전 플로우)
- **올바른 플로우**: 공고등록 폼 직접 열기 (데스크탑: `openPanel('jobPost')`)

#### 3-3. 강사등록 버튼

```tsx
onClick={() => {
  setIsInstructorModalOpen(true);  // ← InstructorInfoModal(안내 모달)
}}
```

- **문제**: InstructorInfoModal (안내/소개 팝업) 오픈, 실제 모달 아님
- **올바른 플로우**: 강사 등록 폼 직접 열기 (데스크탑: `openPanel('instructor')`)

### 데스크탑 플로우 (비교 기준)

- `useSidePanelStore.getState().openPanel('register')` → 구직자 등록 사이드패널
- `useSidePanelStore.getState().openPanel('jobPost')` → 공고등록 사이드패널
- `useSidePanelStore.getState().openPanel('instructor')` → 강사등록 사이드패널
- → 모바일도 동일 패널/모달 플로우를 재사용하거나, 별도 모바일 풀스크린 폼으로 연결해야 함

### 수정 방향

- **3-1. 구직등록**: `setIsTeacherModalOpen(true)` → `window.location.href = '/register?type=talent'` 또는 `useSidePanelStore.getState().openPanel('register')`
- **3-2. 공고등록**: `setIsLocationPickerOpen` → `window.location.href = '/register?type=job'` 또는 `openPanel('jobPost')`
- **3-3. 강사등록**: `setIsInstructorModalOpen(true)` → `openPanel('instructor')` (모달이 아닌 실제 등록 플로우)
- **권장**: `/register?type=talent|job|experience` 쿼리 파라미터 방식으로 `MobileRegister.tsx` 재사용

## 이슈 4. 와글와글 버튼 추가 (스샷4 붉은칸)

### 현황

- 스샷4 기준: 현재위치 버튼(⊙) 아래쪽 빈 공간이 붉은 칸으로 표시됨
- 해당 위치: Hero.tsx L3548~3583 현재위치 버튼 아래 영역
- 사이드 버튼 그룹: `absolute right-3 top-[180px] z-20 flex flex-col gap-2`
  - 구직등록 (sky)
  - 공고등록 (blue)
  - 강사등록 (pink)
  - 현재위치 (white/border) ← 이 아래에 추가

### 수정 방향

- 현재위치 버튼 아래에 **와글와글** 버튼 추가
- **스타일: 브라운에 가까운 진한 노랑 계열 배경 + 흰색 글자 "와글와글"**
- 클릭: `/wagle`로 이동
- 하단 채팅 버튼과 역할 분리: 하단 "채팅" 버튼 → 1:1 채팅 / 사이드 "와글와글" → 커뮤니티

### 버튼 스타일

```tsx
// 브라운에 가까운 진한 노랑 계열 + 흰색 글자

           rounded-xl shadow-lg flex items-center justify-center
```
