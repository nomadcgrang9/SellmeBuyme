## 1. 배경 및 목표

|------|----------|--------------|
| 구직등록 | **중앙 모달** + 뒷배경 블러 | RegionSearchInput (구 단위 → 랜덤 좌표) |

## 5. 공고등록 위치 선택 방식 변경 상세

### 현재 방식 (FullScreenLocationPicker)
```
사용자가 지도를 드래그 → 화면 중앙 좌표 선택 → coord2Address로 주소 역변환
- 장점: 직관적인 지도 인터랙션
- 단점: 2단계 플로우, 전체화면 전환 필요, 모바일에서 불편
```

### 변경 방식 (주소 검색 → 정확한 좌표)
```
사용자가 학교/기관명 또는 주소 검색 → 카카오 API 결과에서 선택 → 정확한 좌표 자동 설정
- 장점: 1단계 플로우, 사이드 패널 내 완결, 학교명 자동입력
- 정확도: 카카오 장소 검색 API가 반환하는 좌표 사용 (건물 단위 정확도)
```

### 위치 정확도 비교

| 등록 유형 | 위치 방식 | 정확도 | 이유 |
|----------|----------|--------|------|
| 구직등록 | 구 단위 검색 → ±500m 랜덤 | 낮음 (의도적) | 개인 위치 노출 방지 |
| 연수강사등록 | 구 단위 검색 → ±500m 랜덤 | 낮음 (의도적) | 개인 위치 노출 방지 |
| **공고등록** | **장소 검색 → 건물 정확 좌표** | **높음 (필수)** | **사용자가 길찾기/거리 판단 필요** |

### 공고등록 주소 검색 API 플로우

```
[사용자 입력: "신백현초등학교"]
         │
         ▼
[카카오 장소 검색 API]
  keyword: "신백현초등학교"
  category: "SC4" (학교)
         │
         ▼
[검색 결과 리스트]
  ┌─────────────────────────────────────┐
  │ 📍 신백현초등학교                     │
  │    경기 성남시 분당구 백현로 12        │
  │    lat: 37.3845, lng: 127.1234      │
  ├─────────────────────────────────────┤
  │ 📍 백현초등학교                       │
  │    경기 성남시 분당구 백현로 50        │
  │    lat: 37.3812, lng: 127.1201      │
  └─────────────────────────────────────┘
         │
         ▼ (사용자 선택)
[미니 지도에 핀 표시 + 주소 확정]
  → 학교/기관명 필드 자동입력
  → 좌표 정확하게 저장
```
