# 260307 "공고등록" → "구인등록" 글귀 개선 플랜

## 1. 개선 배경

사용자 피드백: "공고등록"보다 **"구인등록"**이 더 직관적이고 행위 목적에 부합한다는 의견.

### 핵심 원칙: 하이브리드 접근
- **진입점(버튼/헤더)** = "구인" → 사용자가 하는 **행위** 묘사
- **폼 내부 필드** = "공고" → 작성하는 **결과물** 묘사
- 흐름: "구인하러 들어와서 → 공고문을 작성한다"

- **"공고보기"** 하단 바텀네비 (MobileRegisterNav.tsx): 뷰 전환 맥락, "공고를 본다" → 다른 문맥
- **"공고"** 뷰 타입 라벨 (MobileBottomNav, 필터바 등): "공고 보기" 맥락이므로 다른 문맥
- **동의 문구 내 "구인구직"**: 이미 "구인" 단어 사용 중, 유지
- **placeholder 내 "채용 공고"**: 결과물 지칭이므로 자연스러움
- **docs/ 문서들**: 과거 플랜 문서는 수정하지 않음 (히스토리 보존)
- **DB 스키마, 테이블명, 컬럼명**: `job_postings` 등은 코드 내부이므로 변경 불필요
- **SQL 마이그레이션 파일**: 이미 적용된 마이그레이션은 수정 금지
