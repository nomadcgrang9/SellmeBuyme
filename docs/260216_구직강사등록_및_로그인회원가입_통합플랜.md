## 2. 전화번호 노출 정책

### 2.1 핵심 원칙

```
┌─────────────────────────────────────────────────────────────────┐
│                    전화번호 노출 2단계 보호                      │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│  1단계: 등록 시 선택사항                                         │
│  ┌─────────────────────────────────────────────────────────┐   │
│  │ 전화번호 (선택)                                          │   │
│  │ [010-XXXX-XXXX                               ]          │   │
│  │ [ ] 전화번호 공개 허용                                    │   │
│  │     체크하면 로그인한 사용자에게만 노출됩니다              │   │
│  └─────────────────────────────────────────────────────────┘   │
│                                                                 │
│  2단계: 조회 시 로그인 필수                                      │
│  ┌─────────────────────────────────────────────────────────┐   │
│  │ 비로그인 상태:                                           │   │
│  │   전화번호: [로그인하면 확인 가능]                        │   │
│  │                   ↓ 클릭                                 │   │
│  │             로그인 모달 표시                              │   │
│  │                                                          │   │
│  │ 로그인 상태:                                             │   │
│  │   전화번호: [클릭하여 확인] → 010-1234-5678              │   │
│  └─────────────────────────────────────────────────────────┘   │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

### 2.3 구현 로직

```typescript
// 전화번호 표시 컴포넌트
function PhoneDisplay({ marker, isLoggedIn }: Props) {
  const [revealed, setRevealed] = useState(false);

  // 전화번호가 없거나 비공개 설정인 경우
  if (!marker.phone_number || !marker.phone_public) {
    return null;
  }

  // 비로그인 상태
  if (!isLoggedIn) {
    return (
      <button onClick={openLoginModal} className="text-blue-500">
        [로그인하면 확인 가능]
      </button>
    );
  }

  // 로그인 상태 - 클릭 전
  if (!revealed) {
    return (
      <button onClick={() => setRevealed(true)} className="text-blue-500">
        [클릭하여 확인]
      </button>
    );
  }

  // 로그인 상태 - 클릭 후
  return <span>{marker.phone_number}</span>;
}
```

## 4. 이용약관 전문

### 학교일자리.com 이용약관 (17조)

---

#### 제1장 총칙

**제1조 (목적)**

본 약관은 학교일자리.com(이하 "서비스")의 이용에 관한 기본적인 사항을 규정함을 목적으로 합니다.

**제2조 (정의)**

1. "서비스"란 회사가 제공하는 채용공고 검색, 인력풀 등록, AI 맞춤 추천 등 학교일자리.com을 통해 제공되는 모든 서비스를 말합니다.
2. "회원"이란 본 약관에 동의하고 서비스를 이용하는 자를 말합니다.
3. "인력풀"이란 회원이 자발적으로 등록한 구직자/강사 프로필 정보를 말합니다.
4. "마커"란 지도에 표시되는 채용공고 또는 인력풀 위치 표시를 말합니다.
5. "공고"란 교육청·학교에서 공개한 채용 정보를 말합니다.

**제3조 (약관의 게시 및 변경)**

1. 본 약관은 서비스 내 `/terms` 페이지에 게시합니다.
2. 회사는 관련 법령을 위배하지 않는 범위에서 약관을 변경할 수 있으며, 변경 시 7일 전 공지합니다.
3. 회원이 변경된 약관에 동의하지 않을 경우 서비스 이용을 중단하고 탈퇴할 수 있습니다.

---

#### 제2장 회원

**제4조 (회원가입)**

1. 회원가입은 소셜로그인(Google, Kakao)을 통해 진행됩니다.
2. 가입 시 본 약관 및 개인정보처리방침에 동의해야 합니다.
3. 허위 정보로 가입한 경우 서비스 이용이 제한될 수 있습니다.

**제5조 (회원정보 및 개인정보 수집·이용)**

1. **수집항목, 목적, 보유기간** (개인정보 보호법 제15조)

| 수집항목 | 수집 목적 | 보유기간 |
|----------|-----------|----------|
| 이메일 주소 (필수) | 회원 식별, 로그인, 서비스 이용 알림 | 회원 탈퇴 시까지 |
| 표시명 (선택) | 서비스 내 표시, 인력풀 노출 | 회원 탈퇴 시까지 |
| 역할/관심 지역/과목 (선택) | AI 맞춤 추천, 개인화 서비스 | 회원 탈퇴 시까지 |
| 전화번호 (선택, 인력풀만) | 학교-강사 직접 연락 | 회원 탈퇴 시까지 |

2. **동의 거부권 및 불이익 안내**
   - 필수 정보 제공을 거부할 권리가 있으나, 거부 시 회원가입이 불가합니다.
   - 선택 정보 미제공 시에도 기본 서비스(공고 검색, 지도 탐색)는 이용 가능합니다.

3. **수집하지 않는 정보**: 주소, 주민등록번호, GPS 위치 정보, 신용카드 정보

**제6조 (회원 탈퇴 및 개인정보 삭제)**

1. **탈퇴 절차**
   - 탈퇴는 간편하게 가능합니다.
   - 회원은 언제든지 서비스 내에서 직접 탈퇴를 요청할 수 있습니다.

2. **즉시 삭제 항목**
   - 등록한 인력풀 마커 (구직자/강사)
   - 즐겨찾기 목록
   - 프로필 정보 (이메일, 표시명, 전화번호 등)
   - 추천 캐시 데이터

3. **삭제 방법**
   - 개인정보는 **지체 없이 파기**하며, 복구 불가능한 방법으로 삭제합니다.
   - 법적 보존 의무가 있는 데이터(접속 로그 등)는 관련 법령에 따라 별도 보관 후 파기합니다.

**제7조 (이용 제한)**

다음의 경우 서비스 이용이 제한될 수 있습니다:
1. 허위 정보 등록
2. 타인의 정보 도용
3. 서비스 운영 방해 행위
4. 관련 법령 위반

---

#### 제3장 서비스

**제8조 (서비스의 제공)**

회사는 다음의 서비스를 제공합니다:
1. 채용공고 검색 및 지도 기반 탐색
2. AI 맞춤 추천
3. 인력풀(구직자/강사) 등록 및 노출
4. 즐겨찾기 기능

**제9조 (인력풀 등록 및 노출)**

1. 회원은 자발적으로 인력풀에 등록할 수 있습니다.
2. 등록된 정보는 **서비스 내에서만 공개**됩니다.
3. 전화번호는 **등록자의 공개 허용 설정**에 따라, **로그인한 회원에게만** 노출됩니다.
4. 수집 항목: 표시명, 분야, 경력, 자기소개, 전화번호(선택)
5. 등록 정보는 언제든지 수정·삭제할 수 있습니다.

**제10조 (공고 데이터)**

1. 서비스는 교육청·학교의 공개된 채용공고를 수집·제공합니다.
2. 모든 공고에는 **원본 출처 링크**를 제공합니다.
3. 공고 정보의 정확성은 원본 게시처에 있으며, 서비스는 정보 오류에 대해 책임지지 않습니다.

**제11조 (AI 추천 서비스)**

1. 서비스는 회원 프로필 기반 AI 맞춤 추천을 제공합니다.
2. AI 추천 결과는 **참고용**이며, 채용을 보증하지 않습니다.
3. 추천 알고리즘은 지역, 역할, 과목, 경력 등을 종합적으로 고려합니다.

**제12조 (지도 기반 서비스)**

1. 서비스는 카카오맵 API를 활용한 지도 기반 탐색을 제공합니다.
2. **GPS 위치 정보는 수집하지 않습니다.**
3. 지도 뷰포트 영역을 기준으로 공고/인력풀을 필터링합니다.

#### 제4장 이용자의 의무

**제13조 (이용자의 의무)**

회원은 다음 행위를 하여서는 안 됩니다:
1. 허위 정보 등록
2. 타인의 정보 도용 또는 사칭
3. 서비스의 자동 수집(크롤링) 시도
4. 서비스 운영을 방해하는 행위
5. 불법적인 목적으로 서비스 이용

**제14조 (게시물 관리)**

1. 부적절한 게시물(허위, 비방, 불법 등)은 비공개 또는 삭제될 수 있습니다.
2. 저작권 침해 게시물은 통보 없이 삭제될 수 있습니다.

### 8.1 흐름

```

        ↓

│                                           │

│  • 즐겨찾기 목록                          │
│  • 프로필 정보                            │
│  • 전화번호 (등록한 경우)                  │
│                                           │
│  * 삭제된 정보는 복구할 수 없습니다.      │
│                                           │
│  [취소]              [탈퇴하기]            │

        ↓
Edge Function: auth.admin.deleteUser(userId)
CASCADE → user_profiles, 마커 자동 삭제
        ↓
로그아웃 → 메인 페이지 → 토스트 "탈퇴 완료"
```

### 8.2 Edge Function

```typescript
// supabase/functions/delete-account/index.ts
import { serve } from 'https://deno.land/std@0.177.0/http/server.ts';
import { createClient } from 'https://esm.sh/@supabase/supabase-js@2';

serve(async (req) => {
  const supabaseAdmin = createClient(
    Deno.env.get('PROJECT_URL')!,
    Deno.env.get('SUPABASE_SERVICE_ROLE_KEY')!
  );

  const authHeader = req.headers.get('Authorization')!;
  const token = authHeader.replace('Bearer ', '');

  const { data: { user } } = await supabaseAdmin.auth.getUser(token);
  if (!user) {
    return new Response('Unauthorized', { status: 401 });
  }

  // CASCADE로 연관 데이터 자동 삭제
  await supabaseAdmin.auth.admin.deleteUser(user.id);

  return new Response(JSON.stringify({ success: true }), {
    headers: { 'Content-Type': 'application/json' }
  });
});
```

```sql
ALTER TABLE instructor_markers
```

### 11.4 동의 이력 테이블 (권장)

```sql
CREATE TABLE IF NOT EXISTS user_consents (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  user_id UUID NOT NULL REFERENCES auth.users(id) ON DELETE CASCADE,
  consent_type VARCHAR(20) NOT NULL,  -- 'terms', 'privacy', 'marketing'
  consent_version VARCHAR(10) NOT NULL,  -- '1.0', '1.1' 등
  agreed BOOLEAN NOT NULL DEFAULT true,
  agreed_at TIMESTAMPTZ NOT NULL DEFAULT now(),
  ip_address INET,
  user_agent TEXT,
  created_at TIMESTAMPTZ DEFAULT now()
);

CREATE INDEX idx_user_consents_user_id ON user_consents(user_id);
CREATE INDEX idx_user_consents_type ON user_consents(consent_type);
```
