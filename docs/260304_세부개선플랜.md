4. **디버깅 순서**:
   - Supabase SQL에서 직접 `chat_participants.unread_count` 값 확인
   - 리얼타임 구독 콘솔 로그 추가하여 이벤트 수신 여부 확인
   - chatStore의 `loadUnreadCount()` 반환값 로깅

## 공통 기반 이슈: user_profiles.display_name 미설정 문제

이슈 5, 6, 8에 공통적으로 등장하는 근본 원인:

### 현황
- `user_profiles.display_name`이 NULL이거나 "사용자XXXX" 같은 기본값인 사용자가 존재
- Google OAuth 회원가입 시 프로필이 자동 생성되지 않을 수 있음
- 구직/강사 등록 시 설정한 닉네임이 `teacher_markers.display_name`에만 저장되고 `user_profiles.display_name`에는 미반영될 가능성

### 근본 해결 방안
1. **Auth 트리거**: `auth.users` INSERT 시 `user_profiles` 레코드 자동 생성 + 기본 display_name 부여
2. **프로필 설정 강제화**: 처음 로그인 후 display_name 미설정 시 프로필 설정 모달 강제 표시
3. **마커 등록 시 프로필 동기화**: TeacherMarkerModal/InstructorMarkerModal에서 설정한 닉네임을 `user_profiles.display_name`에도 upsert
4. **채팅/와글 프로필 캐시**: 모듈 레벨 캐시에 TTL 추가하여 일정 시간 후 자동 갱신
