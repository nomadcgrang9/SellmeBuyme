## 3. 정성 분석

### 3.1 긍정 피드백 핵심 키워드

- **"지도"** - 위치 기반 검색의 직관성 (압도적 1위)
- **"통합"** - 여러 교육청 공고를 한 곳에서
- **"D-day 표시"** - 마감일 직관적 확인
- **"원문 링크"** - 교육청 공고로 바로 이동
- **"필요했던 기능"** - 기존에 없던 서비스
