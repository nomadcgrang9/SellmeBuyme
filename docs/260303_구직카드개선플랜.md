# 260303 구직카드 개선 플랜

## 0. 현재 상태 요약

### 문제점
1. **카드 리스트**: 구직자 카드가 공고 카드와 시각적 구분 없이 섞여 있음
2. **정보 부족**: 공고는 3줄(위치/보수/마감) 표시되는데 구직자는 닉네임+뱃지 1줄뿐
3. **뱃지 강조 오류**: "교과과목"이 강조되는데 실제로는 "지구과학"이 더 중요
4. **상세패널 버튼 불필요**: 길찾기(구직자에게 길찾기는 의미 없음), 이메일 버튼 → 정보행으로 전환
5. **구직 상태 표시 없음**: 구직중/구직종료 구분이 안 됨

### 관련 파일
| 파일 | 역할 |
|------|------|
| `Hero.tsx` (2980~3074행) | 카드 리스트 구직자 카드 렌더링 |

| `types/markers.ts` | TeacherMarker 타입, 카테고리 상수 |
| `lib/supabase/markers.ts` | 마커 CRUD 함수 |

## 4. 구직중/구직종료 상태 기능

### 4-1. DB (마이그레이션 불필요)

`teacher_markers.is_active` 필드가 **이미 존재** (boolean, 기본값 true).

현재 관리자 페이지(ContentManagement)에서만 토글 가능.
사용자 본인이 직접 변경하는 UI 없음 → **추가 필요**.

### 4-2. RLS 정책 확인 필요

```sql
-- 확인 사항: 본인 마커 UPDATE 허용 여부
-- 현재 teacher_markers RLS:
--   SELECT: 모든 사용자 (anon 포함)
--   INSERT: authenticated (자기 user_id만)
--   UPDATE: ??? ← 확인 필요
--   DELETE: authenticated (자기 user_id만)
```

UPDATE가 안 되어 있으면 추가 필요:
```sql
CREATE POLICY "Users can update own teacher_markers"
ON teacher_markers FOR UPDATE
USING (auth.uid() = user_id)
WITH CHECK (auth.uid() = user_id);
```

### 4-3. 상태 변경 API

```typescript
// lib/supabase/markers.ts에 추가
export async function toggleTeacherMarkerStatus(markerId: string, isActive: boolean) {
  const { error } = await supabase
    .from('teacher_markers')
    .update({ is_active: isActive, updated_at: new Date().toISOString() })
    .eq('id', markerId)
    .eq('user_id', (await supabase.auth.getUser()).data.user?.id);

  if (error) throw error;
}
```

### 4-4. UI 표시 로직

#### 카드 리스트 칩
```
is_active === true  → ●구직중  (초록 배경, 흰 텍스트, text-[10px])
is_active === false → ○구직종료 (회색 배경, 회색 텍스트)
```

#### 상세패널 (본인 마커일 때만 토글)
```
본인 마커 판별: marker.user_id === currentUser.id

본인일 때:
  [구직중 ●] ← 토글 스위치 (클릭 시 구직종료로 전환)

타인일 때:
  ●구직중  ← 읽기 전용 칩
```

#### 기본 필터링
```
기본값: is_active = true (구직중)만 지도/리스트에 표시
옵션: 하단 필터에 "구직종료 포함" 체크박스 (추후)
```

### 4-5. 사용자 플로우

```
[구직자 본인]
1. 지도에서 본인 마커 클릭
2. 상세패널 열림 → 상단에 "구직중" 토글 스위치 표시
3. 토글 OFF → is_active = false 업데이트
4. 칩이 "구직종료"로 변경, 회색 처리
5. 다른 사용자 지도에서 해당 마커 기본 비노출 (필터)
6. 본인은 항상 본인 마커 볼 수 있음

[학교 담당자 / 다른 사용자]
1. 구직중인 마커만 기본 노출
2. 마커 클릭 → 상세패널에서 "구직중" 칩 읽기 전용
3. 구직종료 마커는 기본 숨김 (추후 필터 옵션)
```
