### 1-2. 등록 플로우 약관·개인정보 동의 현황

**조사 결과 요약**:

| 등록 플로우 | 약관 동의 | 개인정보 동의 | 상태 |
|-------------|-----------|---------------|------|
| OAuth 로그인 → 프로필 설정 (3단계) | ✅ 체크박스 (필수) | ✅ 체크박스 (필수) | **정상** — 회원가입 시 이미 검증됨 |
| OAuth 콜백 → TermsAgreementModal | ✅ 별도 모달 | ✅ 별도 모달 | **정상** — 미동의자 추가 검증 |
| 구직 등록 (TeacherMarker) | — | — | ✅ 회원가입 단계에서 이미 동의 완료 |
| 공고 등록 (JobPostingModal) | — | — | ✅ **별도 동의 불필요** (학교 공고이므로 개인정보 아님) |
| 강사 등록 (InstructorMarker) | — | — | ✅ 회원가입 단계에서 이미 동의 완료 |

**결론**: 회원가입(프로필 설정 3단계)에서 약관+개인정보 동의를 **이미 필수로 받고 있음**.
- `ProfileSetupModal.tsx:457-479` — 이용약관 동의 (필수) + 개인정보 수집 동의 (필수)
- 미체크 시 제출 불가 → DB에 `agree_terms`, `agree_privacy` 저장됨
- 따라서 구직/강사 등록 시 **추가 동의 모달 불필요** (이미 회원인 상태에서만 등록 가능)
- 공고 등록은 학교에서 올리는 공고이므로 **개인정보 동의 자체가 불필요**

**다만 보완이 필요한 부분**:
구직/강사 등록 시 사용자 정보(이름, 전화번호 등)가 **다른 회원에게 공개**되는 점에 대한 안내가 필요.
현재 이 부분은 아래 1-3(전화번호)에서 `phone_public` 플래그로 해결 예정.

### 1-3. 전화번호 기능 점검 결과

**현황**:
| 항목 | 상태 | 상세 |
|------|------|------|
| 프로필 설정에서 수집 | ✅ 선택 입력 | `ProfileStep1Basic.tsx` |
| DB 저장 | ✅ 작동 | `user_profiles.phone` + `teacher_markers.phone_number` |
| `phone_public` 플래그 | ✅ DB에 존재 | `teacher_markers.phone_public DEFAULT false` |
| 로그인 사용자만 노출 | ❌ **미구현** | `TalentDetailModal.tsx`에서 로그인 체크 없이 표시 |
| `phone_public` 체크 | ❌ **미구현** | 플래그 무시하고 항상 표시 |
| 개인정보처리방침 전화번호 기재 | ❌ **누락** | `PrivacyPage.tsx`의 "선택 수집 항목" 테이블에 전화번호가 빠져있음 |

> **개인정보처리방침 전화번호 누락 설명**:
> `PrivacyPage.tsx:56-72`에 "선택 수집 항목" 테이블이 있는데, 여기에 표시명/역할/관심지역/과목/자기소개만 나열되어 있고 **전화번호가 목록에 없음**. 실제로는 프로필 설정에서 전화번호를 수집하고 있으므로, 법적으로 이 테이블에 "전화번호"를 추가해야 함.

**해결 방안**:
1. `TalentDetailModal.tsx` — 로그인 여부 체크 추가
   - 미로그인: `[로그인하면 확인 가능]` 표시
   - 로그인: `phone_public === true`일 때만 표시
2. `PrivacyPage.tsx` — 선택 수집 항목 테이블에 "전화번호" 행 추가
3. 구직/강사 등록 시 전화번호 입력란 옆에 "로그인 회원에게만 공개됩니다" 안내 유지 (현재도 있음)

## 2. 구직등록 카테고리 불일치 수정 (Medium)

### 현상
구직등록 모달의 "주력분야/세부분야" 옵션이 사이트 하단 필터 카테고리와 **심각하게 불일치**

### 비교 분석

**등록 폼** (`ProfileStep2Field.tsx`):
```
교사 레벨: 유치원, 초등, 중등, 특수 (4개)
초등 과목: 담임, 과학, 영어, 체육, 음악, 미술, 실과
중등 과목: 국어, 수학, 사회, 윤리, 물리, 화학, 생물, 지구과학, 영어, 체육, 음악, 미술, 기술·가정, 정보, 상담, 진로, 역사
강사 분야: 요리, 코딩, 음악, 체육, AI교육, 심리상담, 교권보호, 유아놀이, 미술교육, 독서코칭
```

**사이트 필터** (`jobClassifier.ts`):
```
1차: 유치원, 초등담임, 초등전담, 교과과목, 비교과, 특수, 교원연수, 방과후/돌봄, 행정·교육지원, 기타
교과과목: 국어, 영어, 수학, 과학, 사회, 역사, 체육, 음악, 미술, 기가·정보, 도덕·윤리, 제2외국어
비교과: 보건, 상담, 사서, 영양교사
방과후: 체육, 음악, 미술, 무용, 요리, 외국어, 코딩/STEM, 돌봄/늘봄, 기타
행정: 교무실무사, 조리실무사, 시설/환경, 영양사, 학습튜터, 자원봉사, 안전지킴이
```

### 주요 불일치 목록

| 구분 | 필터에 있음 | 등록폼에 없음 | 영향 |
|------|-------------|---------------|------|
| 1차 카테고리 | 초등전담 | ❌ | 초등전담 교사가 등록 시 선택 불가 |
| 1차 카테고리 | 방과후/돌봄 | ❌ | 방과후 강사 역할 선택 불가 |
| 1차 카테고리 | 행정·교육지원 | ❌ | 행정직 구직자 선택 불가 |
| 1차 카테고리 | 비교과 | ❌ | 보건/사서/영양 교사 선택 불가 |
| 교과과목 | 도덕·윤리 | ❌ | 도덕 교사 과목 선택 불가 |
| 교과과목 | 제2외국어 (중국어, 일본어 등) | ❌ | 외국어 교사 과목 선택 불가 |
| 네이밍 | 기가·정보 (통합) | 기술·가정 + 정보 (분리) | 매칭 불일치 |

### 제2외국어 → 개별 언어로 변경
현재 필터에서 "제2외국어"라는 묶음 카테고리 사용 중 → **개별 언어명으로 변경**

현재 `jobClassifier.ts`의 제2외국어 매칭 키워드:
`일본어, 중국어, 프랑스어, 독일어, 스페인어, 한문`

**변경 계획**: 공고 빈도가 높은 순으로 5개를 개별 필터 항목으로 노출
- 현재 3단 필터(`FOREIGN_LANG_TERTIARY_OPTIONS`): 중국어, 일본어, 한문 (3개만)
- 매칭 키워드에는 프랑스어, 독일어, 스페인어도 포함
- → DB 공고 빈도 확인 후 **상위 5개 언어를 개별 항목으로** 등록폼+필터 모두 반영
- "제2외국어" 묶음 라벨 제거, 각 언어를 교과과목 하위에 직접 배치

### 해결 방안
1. `ProfileStep2Field.tsx`의 카테고리를 `jobClassifier.ts` 기준으로 재설계
2. **1차 카테고리** = 필터의 PRIMARY_CATEGORIES와 동일하게 맞춤
3. **2차 카테고리** = 필터의 SECONDARY_OPTIONS와 동일하게 맞춤
4. 제2외국어 → DB 공고 빈도 상위 5개 언어로 개별 항목화
5. 기존 사용자 데이터와 호환성 고려 (DB 마이그레이션 필요 여부 확인)

### 작업 난이도: 중간 (UI 재설계 + 기존 데이터 호환성 검토)
