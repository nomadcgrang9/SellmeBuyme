## 4. 개선이 필요한 부분 (우선순위순)

### 🔴 P0: 즉시 수정 (버그/데이터 오류)

| 문제 | 상세 | 신고자 |
|------|------|--------|
| **동명 학교 매칭 오류** | 여울초등학교 클릭 → 세종 학교 표시 | 예비교사/전북 |
| **학교-지역 매칭 오류** | 서울 해성여고 클릭 → 인천 공고 표시 | 학교교사/서울 |
| **마커 표시 버그** | 지도 확대/축소 시 마커가 사라짐 | 학교교사/경남 |
| **신설 학교 누락** | 경남 진주 금빛초 위치 없음 | 학교교사/경남 |

| 문제 | 요청 횟수 | 상세 |
